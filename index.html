I study how financing and new technologies shape firms’ production processes and product quality.

I use software firms’ source code to track how engineering practices and product quality change over time. I link these measures to data on funding, employment, and acquisitions.

Job market paper

with Labros Pnevmatikos

First PrizeBuchan Prize Paper Competition, Olin Business School

Venture capitalists professionalize how startups are run, from leadership and compensation to hiring policies. We ask whether that influence extends from the boardroom to the codebase. Closer oversight could improve engineering, but pressure to grow could encourage more shortcuts.

We follow 569 software firms, examining each firm’s complete public source code month by month.

Technical debt

Technical debt arises when a design choice lets a firm ship software sooner but makes later changes more costly.

Suppose a feature takes six days to build because engineers have to work around the existing design. With the code reorganized, it would take four. The extra two days are the interest the firm pays each time it makes a similar change. If fixing the design takes five days, those five days are the principal.

We estimate the principal in dollars by valuing the engineering time needed to fix the maintenance problems we identify in each firm’s code.
